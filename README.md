将用户提供的文章改编为平面漫画的制作项目。

## 六步制作流程

1. **架构与视觉规划**：阅读原文，明确叙事框架、总页数、视觉节奏和逐页剧情，输出整体节奏规划。
2. **角色一致性锚点**：建立基础角色与表情 JSON，确定外观、服饰、动作、角度和场景描述。
3. **分批分阶段实施**：依据规划安排批次，每批检查剧情、人物和空间连贯性。
4. **逐页拆解分镜**：输出 `pages/page_01.md` 等文件，标注页面属性、分格、构图和视觉重心。
5. **定版分格细节**：输出 `panels/p01_panel01.md` 等文件，明确画面布局、人物表现、气泡位置和文字。
6. **生图提示词工程**：输出 `prompts/prompt_p01_panel01.json` 等文件，供 Nano Banana 2 使用。

### 强制规范

- 分镜与提示词中的角色描述必须原文引用角色 JSON 中的具体描述，不以文件名或链接代替。
- 按 `[Page X]`、`[Panel 1..N]` 组织；跨页标明 Left Page / Right Page。
- 提示词不包含画幅比例；统一在 Nano Banana 2 中设置。
- 每格提示词要求在右下角生成对应水印，例如 `P01-PN01`。
- 提示词包含统一画风、人物特征、构图、光影、中文对白、旁白与音效字；没有某类文字时明确为空，不自行添加。

完整规范见 [CLAUDE.md](CLAUDE.md)。

## 改编与事实核查边界

- 尊重照护者和被照护者，不把残障者表现为家庭负担，不以羞辱、猎奇或美化伤痛获取关注。
- 辅具不是对所有人的统一处方。选型、适配与使用应由相关专业人员结合个体状况、环境和设备说明评估；漫画不代替医疗建议或操作培训。
- 原文中的研究比例、疾病因果断言、价格、补贴和租赁政策尚未核验。后续引用前需核对出处、样本、适用范围、时间及地区；未核实内容不得包装成确定事实。
- 不虚构研究来源、治疗效果、作者或现实人物身份。新增人物、对白及情节需与原文事实区分。
